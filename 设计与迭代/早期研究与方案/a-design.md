# A「荔影新国风」六幕设计

2026-10-12，用户在三种独立样稿中选择 A，授权将其应用到完整网站。当前版本为 v0.3。课程作业原文继续作为最终要求，参考需求书和图片仅提供项目资料。

## 视觉与内容

- 使用浅青背景、枝叶线描、宋体标题、朱红点缀和圆形鲜果实拍窗口。
- 首屏两行标题错位排列，突出“一盒荔香，赠予所念”；保留清晰品名、礼盒入口和咨询入口。
- 六幕均采用编号、标题、内容说明、统一网格和细线分区。装饰汉字不承担导航或商品信息，并标记为辅助技术忽略。
- 礼盒保留完整实拍和放大功能；果园与公司照片标明为现有素材，不增加未经核实的品牌故事。
- 咨询页保留紧邻字段的演示说明，明确不提交、不保存，不产生订单。

## 章节与转场

底部目录为“初见 / 荔香 / 荔礼 / 果园 / 择礼 / 咨询”，可直接选择任一幕；顶部目录和内容入口也可切换。六幕并非必须依次读完的向导。

切换前捕获当前可见实拍的位置，圆窗从该处扩展并淡出，同时圆形裁切揭示下一幕。无可见实拍时用装饰字窗延续视觉。快速操作取消旧动画；系统减少动态效果时直接切换。

浏览器返回、前进、章节网址和刷新仍定位到对应幕；切换后焦点进入标题。照片、FAQ 和表单的页面内状态得以保留。较长内容在当前幕内滚动，手机不强制缩小正文以塞进一屏。
