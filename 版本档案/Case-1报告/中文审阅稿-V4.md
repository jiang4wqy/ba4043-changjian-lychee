1 项目背景

1.1 公司与产品

我们选择广州市长健农业发展有限公司作为本次营销网站的项目对象。长健农业参与广州增城的荔枝种植与品牌推广。广州市农业农村局在 2025 年 2 月发布的公示中，记录了公司相关负责人建立 180 亩荔枝种植基地、创立“增仙荔”品牌的事迹。[1] 广州市人大网站同年 6 月转载的报道介绍，公司通过与合作社及农户协作开展荔枝种植和推广。[2] 在 2026 年 6 月发布的农业补贴公示中，公司也以荔枝种植主体列出。[3]

项目资料包含企业介绍、公司招牌、荔枝挂果、果肉、礼盒和果园照片。这些素材让我们能够从企业、产品和包装三个方面介绍长健农业。[4] 本次网站集中展示仙进奉荔枝礼盒，围绕亲友送礼和家庭分享组织内容。

1.2 选题与网站任务

选择荔枝礼盒，是因为它有明确的使用场景，也有适合网页展示的实物素材。赠送水果时，购买者除了关心好不好吃，还需要了解包装是否合适、分量能否满足分享，以及寄送时间如何安排。荔枝又具有明显的季节性，因此品种与供应信息也会影响选择。

我们希望网站帮助访客逐步了解产品，再把自己的问题整理成咨询。网站的主要任务是展示荔枝和礼盒、说明购买前需要考虑的事项，并提供可填写、可保存的咨询入口。这样的目标让每个章节都有具体作用，也便于检查访客能否完成整个流程。

2 调研方法与发现

2.1 查阅了哪些资料

我们在 2026 年 10 月 11—12 日整理企业资料，观察产品照片，并查阅公开网页。调研重点放在三个问题上：长健农业具有什么产品背景，荔枝礼盒如何在市场上呈现，以及访客选择礼盒时需要了解哪些信息。

企业部分阅读了项目需求书、广州市农业农村局的公示和广州市人大网站的相关报道；产品部分查阅了广东省农业科学院的仙进奉品种介绍；市场部分阅读了羊城晚报和增城政府门户的荔枝报道；商品信息部分观察了京东“增城荔枝”聚合页面；保存与收货部分参考了重庆市市场监督管理局的消费提示。这次研究采用资料查阅和页面观察，记录的是各类信息如何被呈现，以及它们对本项目的启发。

我们还通过政府公示和相关新闻检索长健农业及“增仙荔”的品牌相关信息，了解企业的种植与推广背景。[1][2] 结合产品和包装图片，我们整理出品牌介绍、产品特点和礼赠展示三类内容。[4] 礼盒外观、内盒与包装细节集中放入相册，企业与果园内容用于介绍品牌和产品来源。

2.2 市场与商品信息

羊城晚报关于荔枝销售的报道介绍了从化“流溪红”进入精品礼盒渠道的案例；增城政府门户的报道则展示了荔枝风味图和表达心意的礼盒。[5][6] 这些案例让我们看到，荔枝除了作为鲜果销售，也有结合包装与情感表达的礼赠应用。结合长健农业的产品与包装，我们决定以荔枝礼盒为网站的重点推广内容，增加探亲、致谢和家人分享三个选礼场景。

商品页面将品种和重量直接写在标题中，品种资料与消费提示也涉及成熟时令和鲜果保存。[7][8][9] 因此，网站在图片之后提供品种介绍、规格与数量提示，并在常见问题中说明寄送和保存，帮助访客准备咨询。

3 目标受众与访客行动

主要受众是准备给亲友送水果礼盒的个人消费者，次要受众是希望与家人分享鲜果的人。前者需要判断礼盒是否适合赠送，并安排数量和时间；后者更关心产品特点、分享分量和保存方式。我们的内容围绕这些任务展开。

网站希望访客完成的行动是提交产品咨询。一个典型流程是：从首页进入礼盒章节，查看包装照片，选择送礼场景，阅读相关说明，再填写联系方式和问题。提交的信息保存到项目后台，供小组查看和整理。表单成功后显示咨询编号，使访客得到明确反馈。

为便于直接沟通，我们还在咨询章节末尾补充电话 13316022555 和微信二维码。访客可以通过电话链接联系，或打开二维码原图后使用微信识别。[10]

为了让不同访客都能找到入口，首页和目录提供直接咨询链接，礼盒、选礼清单和常见问题也连接到表单。熟悉产品的人可以直接咨询，第一次了解产品的人则可以先浏览详细内容。

4.2 视觉与文字

我们采用浅绿色背景、深绿色正文和宋体标题，使页面与水果、果园主题保持联系。少量红色印章和枝叶图案增加国风细节，圆窗则让荔枝照片形成清晰的视觉中心。首屏“一盒荔香，赠予所念”表达礼赠意味，旁边保留产品名称与行动入口，方便访客继续浏览。

咨询末尾的联系卡沿用绿色、细边框和宋体标题，与原有页面保持一致。桌面上文字与二维码左右排列，手机上改为上下排列，电话链接与二维码都可以通过章内滚动到达。

诗意文字主要用于标题，品种、规格和流程说明使用直接的表达。这样既保留品牌氛围，也能让访客读懂实际信息。正文用段落和对齐的信息区组织，手机上改为单列；长答案放入可展开的常见问题，减少同一画面中的文字量。

4.3 导航与场景选择

页面采用分章浏览。点击目录后，圆窗转场带出下一章，底部目录仍然可见，当前章节也有标记。地址中的 #gift、#enquiry 等片段支持直接定位，浏览器返回、前进与刷新保持对应章节。

礼赠场景的作用是帮助访客准备咨询。例如选择“致谢相赠”后，页面会显示与该场景有关的说明，点击咨询入口会带入主题和问题草稿。如果访客已经填写正文，原有输入会保留。相册切换、照片放大和常见问题展开也都提供可见响应。

开场动画可以跳过或重播。页面响应减少动态效果的系统偏好，采用直接切换并关闭自动开场；不运行 JavaScript 时，六章内容仍可作为普通长页面阅读。

5 网站制作与技术说明

5.1 技术选择

我们使用 HTML、CSS 和 JavaScript 组织页面、调整布局并实现交互。咨询功能由 Flask 处理请求，SQLite 保存记录，Waitress 运行网站服务。[11][12][13] 这套结构将产品展示与咨询收集连接起来，既可以本地运行，也可以部署到服务器。

处理章节切换、圆窗转场、相册、选礼场景和表单反馈。

6.2 部署过程

网站于 2026 年 10 月 12 日部署到 Ubuntu 22.04 服务器，使用 Python 3.10.12 和独立虚拟环境。Waitress 监听 127.0.0.1:8051，Caddy 2.11.4 提供 HTTPS 反向代理与证书，systemd 管理应用进程并设置开机启动。[20] 数据库、管理密码哈希和会话密钥位于 /var/lib/changjian-agri，与代码版本目录分开。

上线后检查了 HTTPS 证书、网页资源、咨询提交和管理登录，再重启应用服务确认记录保留。17 个运行文件的 SHA-256 与交付源码一致，源码压缩包完整性检查通过。网站可通过本报告开头的完整网址访问。

6.3 本地运行

源码包包含网页、后端、依赖和 README。完整解压后，在 Windows 创建虚拟环境、安装锁定依赖并启动：

python -m venv .venv.venv/Scripts/python.exe -m pip install --no-index --find-links vendor/wheels -r requirements-lock.txt.venv/Scripts/python.exe app.py --setup.venv/Scripts/python.exe app.py

设置管理密码后，浏览器打开 http://127.0.0.1:5000/，管理页为 /admin。离线安装检查使用了 Windows Python 3.9.13 和 Ubuntu x64 Python 3.10.12；Linux 启动方法在 README 中说明。
