# B站公开评论采集

试采 5 条，扩样后共 20 条，来自 14 个公开视频的评论区。两个 CSV 的前 5 条相同。每条在不同时间独立打开同一原页，核对原文、发表时间、主评或回复层级；页面给出评论 ID 时，也核对该 ID。包括一条视频发布者在评论区给出的应季选购建议，已在上下文中标明。点赞、视频弹幕、简介文字均不计入。

## 读取与筛选

Python 3.12 通过本机 BrowserOS Neo 的标准 MCP 桥访问正常网页，滚动至评论区，等候页面渲染。页面的公开评论组件使用开放的 Shadow DOM，由 `read_comments.js` 读取可见文字，表情保存为页面上的文字标签。无需账户凭据。请求开放接口遇到 HTTP 412 后，改用正常的视频网页。

`raw` 保留采集时页面展示的公开评论及已展开的回复，按主评与其回复的显示顺序记录；不含用户资料或浏览器凭据。首次采集和复核各自独立保存，浏览器可能重排热门评论。浏览器仅展示部分公开评论时，换相关视频。服务重连后个别备用页未能完成双访，未据此补造记录。

`selection.json` 和 `selection_full.json` 保存 AI 助手按研究问题逐条筛选后的视频编号、原页显示顺序、主题及上下文。保留具体选择理由、疑问和收货经验，去重并剔除过于笼统、跑题和促销的内容。不同页面的来源在 CSV 中逐条注明。数据包含其他荔枝品种、苹果、车厘子等相关对照样本；不得将其改写为长健农业客户评价，也不宜用这组便利样本推算消费者占比。

## 复现

在此目录运行，可直接从原始快照重建并复核两份表：

```powershell
py -3.12 -B collect.py build
py -3.12 -B collect.py full
```

如需回到公开网页重新抓取，例如双访第一条来源：

```powershell
py -3.12 -B collect.py both BV1RX4y1A7i7
```

联网采集使用 Node.js 与 BrowserOS Neo 本机桥，默认路径为 `F:/AppData/BrowserOS-Neo/maintenance/bridge/bridge.mjs`。其他安装位置通过环境变量 `BROWSEROS_NEO_BRIDGE` 指定。已有的原始快照保留，新快照以时间戳区分。重新访问时在线展示顺序或内容可能变化。

CSV 采用 UTF-8 BOM。所有收集、复核时间均为北京时间。`source_id` 仅填页面公开链接中的评论编号，未展示的留空。`id` 为视频编号、评论发布时间和完整原文的 SHA-256 前 12 位加平台前缀。出现在线排序变化时，使用第一次记录到原文的快照作为采集证据，严格选择晚于它的另一份快照复核。无独立评论链接的记录保留视频原页链接、评论发表时间及位置，能与本地快照对应。
