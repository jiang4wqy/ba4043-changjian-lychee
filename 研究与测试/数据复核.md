# 从原始记录复核 Excel

[研究数据总表](研究数据总表.xlsx)按样本编号连接正式评论与[逐条编码](BA4043-用户需求分析/逐条编码.csv)。在“主题统计”中选中任一平台数值可查看计数公式；在“编码摘录”中可找到该主题的原文依据。“收到的互评”对应七个同名文件，“本组对外评阅”对应六组的[逐段原文](本组评阅其他组/逐段评阅.csv)。

在本目录打开 PowerShell，使用 Python 3.12 并安装 `requests`、`beautifulsoup4` 与 `matplotlib`。下列命令重放已保存的两次采集快照：

```powershell
cd BA4043-评论采集/B站
python collect.py build
python collect.py full
cd ../京东
python full_jd.py build full_raw full-replayed.csv
cd ../知乎
python collect.py --replay --sources sources-full.txt --raw-dir raw-full --review review-full.csv --limit 20 --csv full-replayed.csv
cd ..
python 合并样本.py
python 合并样本.py --full
cd ../BA4043-用户需求分析
python 分析评论.py
```

京东和知乎重放表的样本编号与评论正文应逐行等于各目录的 `full.csv`；三站合并后各 20 条。公开快照统一把 B站回复中的用户名写作“[用户]”，保留原样本编号以便联查。平台原始评论号与网址里的内容编号属于来源索引。

原始[选盒测试 Excel](BA4043-目标与衡量/选盒测试记录.xlsx)含任务卡、评分公式和 10 个观察位。上线验收见[功能检查](../展示素材/功能检查.md)；本次整理未取得服务器每日事件的新导出，归档保留 11 月 25 日的既有验收记录。
