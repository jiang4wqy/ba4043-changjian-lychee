# 组内互评填表规则

原表栏目为成员姓名、学号、0–10 分整数评分、职责或评语。以下保留原表评分说明。原表按人分发，个人得分及评阅身份保留在提交副本中。组间网站互评全文见[收到的七份反馈](原始互评/)及[本组评阅的六个项目](本组评阅其他组/)。

Each student should complete and submit one peer evaluation file. Please evaluate all other group members.

1. Score
Choose a whole number from 0 to 10. The default score is 5.
5 means the member's contribution was at the expected level. Use a higher score for a greater contribution and a lower score for a smaller contribution.
10 means the contribution was far above the expected level; 0 means it was far below the expected level.

2. Responsibility / Evaluation Comment
Briefly state each member's responsibility and give a specific reason for the score. If you leave this comment blank, the score will be treated as 5.
Comments such as "good" or "helpful" are not enough. Refer to the member's actual contribution, work quality, cooperation or reliability.

Self-evaluation is optional.
